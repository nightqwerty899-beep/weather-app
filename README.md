# Weather App

Приложение погоды на HTML, CSS и JavaScript без фреймворков и сборщика. Показывает текущую погоду и прогноз по названию города. Данные получает из OpenWeather API.

## Возможности

- Поиск города с подсказками после ввода двух символов.
- Текущая температура, ощущаемая температура, влажность, давление и скорость ветра.
- Прогноз до пяти дней с иконками и описанием погоды на русском языке.
- История пяти последних городов и сохранение последнего выбранного города.
- Кеш ответов на пять минут, до пяти городов за одну сессию страницы.
- Кнопка обновления с повторным запросом данных, минуя кеш.
- Сообщения об отсутствии сети, неизвестном городе и ошибках API.

## Запуск

Из папки проекта запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Откройте [localhost:8000](http://localhost:8000). Нужны современный браузер и интернет для получения погоды. Устанавливать npm-пакеты и собирать проект не требуется.

Открывать `index.html` двойным щелчком не нужно: приложение использует ES-модули, для которых необходим HTTP-сервер.

## Как устроен код

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка поиска, истории, текущей погоды и прогноза |
| `style.css` | Оформление карточек, подсказок и индикатора загрузки |
| `main.js` | Обработчики событий и взаимодействие всех модулей |
| `api.js` | Запросы погоды, прогноза и городов, обработка ошибок HTTP |
| `ui.js` | Отрисовка данных и управление состоянием интерфейса |
| `storage.js` | История городов и последний город в `localStorage` |
| `cache.js` | Кеш ответов в памяти с ограничением размера и срока жизни |
| `utils.js` | Debounce, объединение подсказок, перевод давления и выбор записей прогноза |
| `GUIDE.md` | Подробный разбор кода учебного проекта |

При поиске города приложение параллельно запрашивает текущую погоду и прогноз. Повторный поиск в течение пяти минут использует кеш. После истечения срока отображается предложение обновить данные. Кнопка «Обновить» всегда запрашивает свежую погоду.

Подсказки используют задержку 400 мс после ввода; предыдущий выполняющийся запрос отменяется через `AbortController`. Подсказки из кеша объединяются с результатами геокодирования без дубликатов.

История сохраняется между посещениями в `localStorage`, а кеш погоды существует только до перезагрузки страницы. При следующем открытии последний город подставляется в поле поиска; для загрузки погоды нужно нажать кнопку или Enter.

## API и прогноз

В `api.js` находятся адрес OpenWeather и `API_KEY`. Ключ оставлен в клиентском коде; при необходимости его можно заменить своим значением.

Приложение обращается к `/data/2.5/weather`, `/data/2.5/forecast` и `/geo/1.0/direct`. Единицы измерения — метрические, язык описаний — русский. Давление переводится из гПа в мм рт. ст.

Для каждого дня из трёхчасового прогноза выбирается одна запись, ближайшая к полудню по локальному времени браузера. Это отдельная точка прогноза, а не средняя температура за сутки. Приложение показывает до пяти таких записей.
